# 2.5.0 发布说明

应用版本 2.5.0 于 2026-09-26 发布 Docker；2026-09-30 将源码、中文文档和协作 CI 发布到本仓库。

## 功能

适配 CPAMP v1.14.1 的只读能力：Meta/Muse、Devin 和 xAI 已保存配额，未知进度，多窗口，Devin 缓存计费，历史明细覆盖提示，以及新增的用量状态页。保留 Codex 完整普通池 / Spark 额度、Access Guard 公开名单与模型不一致诊断。修复无 Key 历史汇总误触发筛选 400。

## 已验证范围

2026-09-26 发布验收：前端 233 个测试文件 / 3,065 项测试、后端测试/race/vet、真实隔离 CPAMP v1.14.1 联调、60 项接口边界、18 个常规浏览器场景和 6 个历史归档场景。使用合成 CPA/提供方数据；这些结果不代表任意真实提供方账号都可用。Windows 程序当时完成交叉编译，未做 Windows 实机验收。

本次 GitHub 发布额外增加开发代理、部署说明、协作指南、CI，以及无私人地址的 Windows 启动脚本。应用服务端逻辑未更改。GitHub CI 的当前结果见仓库 Actions。

## Docker 与下载

原 Docker 标签 `jinshenganyuci/cpamp-viewer:2.5.0` 的发行 digest：

`sha256:2f2b94ecb5e8c28525b9c441494151b6003e5d2f17a5caeed69cd9d508dd699e`

GitHub Release 的 Linux 离线镜像复用该发行镜像；Windows 可执行文件复用已验证构建的字节。外层部署包、启动脚本、文档与校验文件针对源码公开重新整理；未重推 Docker Hub 镜像。

公开后的 Dockerfile 将源码标签指向本仓库并加入 Viewer LICENSE；今后从源码重建时，镜像元数据与旧发行镜像不同，不承诺重建得到相同 digest。

镜像和二进制包的版本号描述应用版本；包的完整性以 Release 同时提供的 SHA-256 文件为准。
